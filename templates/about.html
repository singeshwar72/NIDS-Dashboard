Abstract

This Network Intrusion Detection System (NIDS) dashboard is a full-stack cybersecurity application designed to analyze network traffic data, detect suspicious patterns, and generate actionable security alerts. The system demonstrates the intersection of computer networking, cybersecurity principles, machine learning, and modern web development.

Detection Methodology

Rule-Based Detection
  • High Connection Frequency
  • High Packet Rate
  • Large Traffic Volume
  • Abnormal Byte Ratio
  • Suspicious Destination Ports
  • Fast Connection Rate
  • Small Packet Anomaly
  • High Bandwidth Usage
Machine Learning
  • Algorithm: Random Forest
  • Classes: Normal / Suspicious / High Risk
  • Features: 15 engineered features
  • Fallback: Rule-based if model unavailable
  • Conservative: ML can only raise, not lower risk

Security Features

  • Parameterized SQL queries (no SQL injection possible)
  • Input validation on all uploaded data
  • File extension and size validation
  • Security headers on all responses
  • Safe error handling (no stack traces to users)
  • No shell execution, no eval(), no exec()
  • No hard-coded secrets (environment variables only)
  • Defensive-only: analyzes supplied data, generates no attacks
